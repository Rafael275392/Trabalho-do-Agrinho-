# Agro Forte - Futuro Sustentável

O **Agro Forte** é um site institucional (Landing Page) moderno e elegante focado no agronegócio consciente, tecnologia no campo e práticas sustentáveis. 

Este projeto combina uma estrutura semântica em **HTML5** com uma estilização robusta e interativa em **CSS3**, resultando em uma interface limpa, visualmente atraente e com excelente usabilidade.

## Sobre o Projeto

O objetivo do site é divulgar a importância do agronegócio moderno. A página foi desenhada para passar credibilidade e profissionalismo, utilizando uma paleta de cores voltada para tons de verde e elementos visuais que remetem à natureza e à alta tecnologia no campo.

## Funcionalidades e Design

* **Menu de Navegação Fluido:** Links do tipo âncora que levam o usuário suavemente até a seção desejada (`Início`, `Sobre`, `Sustentabilidade` e `Contato`).
* **Seção Hero de Alto Impacto:** O topo do site preenche toda a tela (`100vh`) e traz uma imagem de fundo imersiva obtida via Unsplash. Há um efeito de sobreposição escura (*overlay*) para garantir o contraste e a leitura perfeita dos textos.
* **Cards Interativos:** A seção de sustentabilidade exibe blocos de informações com sombras suaves (`box-shadow`) e um efeito visual de elevação (`transform: translateY`) quando o usuário passa o mouse por cima (*hover*).
* **Botões com Transição:** Botão de chamada para ação (*Call to Action*) com mudança de cor suave (`transition: 0.3s`).
* **Rodapé Institucional:** Área limpa com informações de contato e direitos autorais.
